# Vault Layer

Trusted-bot registry, access granting, irreversible burn, reputation ledger.

## Purpose
A place where trusted bots live. Banks and families grant access because the chain proves the bot earned it.

## Components
- trusted_bot_registry.md
- access_granting.md
- burn_function.md
- reputation_ledger.md
- vault_manager_bot_prompt.md

## Burn Rule
Once a bot is destroyed, the burn function is irreversible. No multisig, no timelock, no override can revive that bot ID. The attestation record stays on-chain forever.
